## 8. 使用示例

### 8.1 Linux环境下启动应用

```bash
export BOOTADMIN_URL="http://bootadmin.example.com"
export DATASOURCE_URL="jdbc:mysql://db.example.com:3306/aopa?useUnicode=true&characterEncoding=utf8"
export DATASOURCE_USERNAME="aopa_user"
export DATASOURCE_PASSWORD="aopa_password"
export REDIS_HOST="redis.example.com"
export REDIS_PASSWORD="redis_password"
java -jar aopa-admin.jar
```

### 8.2 Docker环境下启动应用

```bash
docker run -d \
  -e BOOTADMIN_URL="http://bootadmin.example.com" \
  -e DATASOURCE_URL="jdbc:mysql://db.example.com:3306/aopa?useUnicode=true&characterEncoding=utf8" \
  -e DATASOURCE_USERNAME="aopa_user" \
  -e DATASOURCE_PASSWORD="aopa_password" \
  -e REDIS_HOST="redis.example.com" \
  -e REDIS_PASSWORD="redis_password" \
  --name aopa-admin \
  -p 8080:8080 \
  aopa-admin:latest
```

## 9. 注意事项

1. 所有环境变量均为可选配置，若不设置则使用默认值
2. 敏感信息(如密码、密钥)建议通过环境变量传入，避免硬编码在配置文件中
3. 环境变量名不区分大小写，但建议使用大写字母和下划线的组合以提高可读性
4. 修改环境变量后需要重启应用才能生效
5. 部分环境变量的默认值包含占位符(如`@monitor.username@`)，这些占位符会在构建时被替换为实际值
